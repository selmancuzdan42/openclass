# Ekran Görüntüleri

Bu görüntüler, arayüz geliştirme için kullanılan **sahte veriyle** alınmıştır
(`src/dev-mock.ts`): örnek bir laboratuvar, LAB101–LAB204 arası cihazlar,
iki yardım talebi ve açık bir ders oturumu. Ekran içerikleri gerçek öğrenci
masaüstleri değil, geliştirme sunucusunun ürettiği yer tutucu çizimlerdir.

Küçük resimler üretimdeki yolu kullanır: sahte sunucu da gerçek `ocframe://`
ile aynı ikili biçimde bölge paketi döndürür ve birleştirme aynı
`ScreenCanvas` bileşeniyle yapılır.

| Dosya | İçerik |
|---|---|
| `ogretmen-konsolu-acik.png` | Öğretmen konsolu, açık tema, küçük resim ızgarası |
| `ogretmen-konsolu-koyu.png` | Aynı ekran, koyu tema |
| `ogretmen-ayrintili-liste.png` | Ayrıntılı tablo görünümü |
| `ogrenci-yapilandirma.png` | Öğrenci yapılandırma penceresi (öğretmen/yönetici içindir) |
| `ogrenci-mesaj.png` | Öğretmen mesajı açılır penceresi |
